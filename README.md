Reproducible Snakemake workflow for human bulk RNA-seq quality control, adapter trimming,
splice-aware genome alignment (STAR + featureCounts), alignment-free transcript quantification
(Salmon), and alignment quality evaluation (RSeQC + deepTools + MultiQC).
## Dataset
- **Study:** GSE52778 (`SRR1039520`, `SRR1039512`, `SRR1039517`, `SRR1039514`)
- **Reference:** GRCh38 primary assembly, GENCODE Release 50
